DesignToCodeAgent

From Figma File
to Production Code

Give the agent a Figma URL. It reads the entire design file, extracts tokens and components, builds a platform-agnostic Intermediate Representation (IR), validates quality with an LLM critic, then generates clean, idiomatic mobile code.

  • ✓ Direct Figma API integration with full design token extraction
  • ✓ Platform-agnostic IR decouples design parsing from code generation
  • ✓ LLM critic validates accessibility and structure before generating
  • ✓ React Native & Flutter output with correct auto-layout mapping
  • ✓ Iterative retry loop — automatically re-builds IR on critic failure
  • ✓ 37 unit + integration tests · TypeScript strict · zero any

System Architecture

Key technical decisions behind the platform.

🔗
LangGraph State Machine
Each node operates on a shared WorkflowState with append-reducer semantics for logs and errors. Conditional edges handle early exit, retry loops, and routing decisions — all type-safe via Annotation.Root.
📦
Monorepo Architecture
pnpm workspaces + Turbo build cache. Each agent lives in its own package (packages/agents/*) with independent versioning, test suites, and build targets. Shared types flow through @appvelocity/shared-core.
🤖
LLM Abstraction Layer
A LLMClient interface wraps Anthropic's API with JSON-mode support and a setLLMClient() testing hook. Swap to GPT-4o or any provider by implementing two methods.
⚡
Real-time Streaming
The Next.js dashboard streams workflow events via Server-Sent Events. Every log entry, progress tick, and final code bundle is pushed to the browser as it happens — no polling required.
🛡️
Rate Limiting & Caching
FigmaClient uses p-queue to enforce Figma's 60 req/min API limit. LRU cache with 5-minute TTL prevents redundant fetches. Axios-retry with exponential backoff handles transient failures gracefully.
🧪
Test Coverage
78+ tests across unit, integration, and workflow layers. Vitest with module mocking isolates each node. Integration tests exercise the full LangGraph graph with mocked FigmaClient and LLM responses.
