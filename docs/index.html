System Design

Key Architectural Decisions

The technology choices that make AppVelocity fast, reliable, and extensible.

🔗
LangGraph State Machine
Each node operates on a shared WorkflowState with append-reducer semantics for logs and errors. Conditional edges handle retry loops and routing — all type-safe via Annotation.Root.
📦
pnpm Monorepo
Turborepo build cache + pnpm workspaces. Each agent lives in packages/agents/* with independent versioning and test suites. Shared types flow through @appvelocity/shared-core.
🤖
Swappable LLM Client
A LLMClient interface wraps Anthropic's SDK with JSON-mode support and a setLLMClient() test hook. Switch to GPT-4o or any provider by implementing two methods.
⚡
Real-time SSE Streaming
The Next.js dashboard streams workflow events via Server-Sent Events. Every log entry, progress tick, and code bundle is pushed to the browser in real-time — no polling required.
🛡️
Rate Limiting & Caching
FigmaClient uses p-queue to enforce Figma's 60 req/min API limit, LRU cache with 5-min TTL, and axios-retry with exponential backoff to handle transient failures.
🧪
78+ Tests, Strict Types
Vitest with module mocking isolates each node. Integration tests exercise the full LangGraph graph. TypeScript strict mode with zero any across all packages.
